## [0.1.0] - 2026-11-23

### Added

- Signal's colors for light and dark (`colors`), the code panel's text colors (`panelText`), type families (`fonts`), easings, named motion durations and corner radii.
- `@dotquad/tokens/tokens.css`: the tokens as CSS custom properties, dark by `data-theme="dark"` or the system setting.
- `ICONS`: Dotquad's icons for the extensions (24 × 24, 1.75 stroke) as inner SVG markup. Brand artwork, not MIT licensed: see `TRADEMARKS.md`.
- The package holds what Dotquad's browser, VS Code and Raycast extensions use; the website's map, navigation and other icons stay in the website.
