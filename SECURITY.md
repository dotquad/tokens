# Security policy

## Supported versions

Only the latest version of `@dotquad/tokens` on npm gets security fixes.

## Reporting a vulnerability

Please report it privately through GitHub's
[private vulnerability reporting](https://github.com/dotquad/tokens/security/advisories/new), not in a
public issue. You'll hear back within a few days. Once a problem is confirmed, the fix ships in
a new release and a [security advisory](https://github.com/dotquad/tokens/security/advisories) is
published.

Problems in dotquad.app or the Dotquad API (`api.dotquad.app`) can be reported the same way,
here.
